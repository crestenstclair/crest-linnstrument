Connecting…

Select slot. Record, then play the virtual LinnStrument. Finish take; click slot again to launch. In Clip pads mode, bottom-row pads 1–8 launch recorded slots or stop playing slots. Click the selected playing slot to stop it.

HARMONY · chord pads and strumplate

Chord pads: seven adjacent input pitches select I–VII, repeating. Strumplate: select a degree here, then pick successive pads for chord tones across octaves. Input anchor 30 matches stock bottom-left pad. Held voices keep their pitch; changes affect new attacks. Both use stock firmware MPE. Play mode returns to ordinary notes.

ACCOMPANIMENT · Euclidean rhythm and seeded pitch lane

Stop selected slot before generating, changing follow mode, or freezing. Changes support Undo. Different slots loop independently. Timing variation delays attacks within each step. Following changes future attacks only; freeze stores the currently selected harmony as fixed pitches.

OUTPUT · explicit MIDI destination profiles

Stop transport before changing profiles. MPE is required for independent X/Y/Z. Ordinary MIDI rejects overlapping identical pitches. Monophonic reduction sounds the last held note and reattacks the preceding note on release. Profiles save with host sessions; plain library sessions open with lower MPE defaults.
