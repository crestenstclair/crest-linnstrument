HARMONY · chord pads and strumplate

In Play mode, latch 1–5 notes, select a degree, then Learn. Uses live notes on the selected slot's track; preserves unisons. Release fingers before switching to Chord pads. Learned pitches stay fixed when tonic, scale or chord quality changes; inversion, register, spread, voice leading and articulation still apply. Root defaults to the lowest note. Learning and restoring support Undo; recording must be idle.

Chord pads: seven adjacent input pitches select I–VII, repeating. Timed strum sweeps a held chord. Humanized chord adds seeded attack delay and velocity variation; each new finger gets a repeatable variation. Release cancels tones still waiting. Bass and manually picked strumplate notes stay immediate and keep their original velocity. Arpeggio repeats chord tones while held; gate sets each note length and cannot exceed step spacing. Release cancels future tones. Expression follows the held finger through each repeat. Bass stays held and attacks immediately. Strumplate: select a degree here, then manually pick successive pads for chord tones across octaves. Input anchor 30 matches stock bottom-left pad. Held voices keep their pitch and timing; changes affect new attacks. Both use stock firmware MPE. Play mode returns to ordinary notes.

ACCOMPANIMENT · Euclidean rhythm and seeded pitch lane

Stop selected slot before generating, changing follow mode, or freezing. Changes support Undo. Different slots loop independently. Timing variation delays attacks within each step. Following changes future attacks only; freeze stores the current follower harmony as fixed pitches. A clip source uses its recorded chord gestures, including timing before delayed strums. Its last chord carries across loop pickup gaps; stopping it restores live/selected harmony. Empty slots and clips without chord gestures use live/selected harmony. Editing rendered notes does not rewrite recorded chord intent.

OUTPUT · explicit MIDI destination profiles

Stop transport before changing profiles. MPE is required for independent X/Y/Z. Ordinary MIDI rejects overlapping identical pitches. Monophonic reduction sounds the last held note and reattacks the preceding note on release. Profiles save with host sessions; plain library sessions open with lower MPE defaults.
